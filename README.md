# New Game Project

A household-rooted civilization sandbox in Godot 4.6. Start with `project.md` (what it is), `CLAUDE.md` (how to work in it) and `AGENTS.md` (binding rules).

Validate: put your Godot executable's path in `.godot-exe`, then run `$env:GODOT_BIN = (Get-Content .godot-exe).Trim(); .\scripts\validate_project.ps1`.
